Sobre mim

Sou estudante de Análise e Desenvolvimento de Sistemas no Instituto Federal de São Paulo. Nas aulas, aprendi que um bom sistema começa antes do código: começa entendendo quem vai usá-lo e qual problema ele precisa resolver.

Por isso, nos meus projetos eu converso com quem vive o problema, levanto os requisitos, desenho a interface no Figma e só depois programo. Todos os meus trabalhos foram feitos em grupo, então também aprendi a dividir tarefas, alinhar decisões e entregar junto com a equipe.

Hoje trabalho com C, Python, JavaScript, TypeScript, Java e SQL, e já construí sistemas completos: site web, sistema de gestão e aplicativo mobile.

Cantina Fatore

Sistema web para controlar estoque e vendas da cantina de uma escola, no lugar das anotações feitas à mão.

  • Cadastro de produtos e de funcionários, com cada venda ligada a quem comprou
  • Relatório de vendas exportado para Excel
  • Arquitetura MVC em Flask, com herança nas classes de relatório
  • Requisitos levantados em entrevista com a administradora da cantina
  • Python
  • Flask
  • MySQL
  • Tailwind CSS
  • JavaScript

Receitech

Site de receitas completo, feito para demonstrar um CRUD de ponta a ponta com backend estruturado e banco relacional.

  • Cadastro, login e sessão de usuários
  • Publicação de receitas com upload de imagem, edição e exclusão
  • Comentários e navegação por categorias
  • Layout responsivo, prototipado antes no Figma
  • Node.js

Aplicativo de Reserva de Salas
